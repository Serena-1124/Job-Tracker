# JobTracker 求职进度管理 - 产品需求文档 (PRD)

## 1. 产品概述

### 1.1 产品名称
JobTracker - 求职进度管理工具

### 1.2 产品定位
一款面向求职者的个人进度管理工具，帮助用户系统化追踪求职全流程，从投递简历到最终offer的每一个环节，让每一次投递都有迹可循。

### 1.3 核心价值主张
- **告别混乱**：不再用Excel或备忘录零散记录，统一管理所有求职信息
- **进度可视**：清晰掌握每个投递的当前状态，避免遗漏重要环节
- **经验沉淀**：记录面经和待办事项，形成个人求职知识库
- **数据安全**：本地+云端双存储，换设备不丢数据

---

## 2. 目标用户

### 2.1 主要用户群体
- **应届毕业生**：首次求职，需要系统化管理大量投递
- **职场跳槽者**：同时投递多家公司，需要追踪不同进度
- **长期求职者**：求职周期较长，需要记录历史投递和面经

### 2.2 用户痛点
1. 投递了太多公司，记不住每家公司的进度
2. 面试后忘记记录面经，下次面试无法复盘
3. 待办事项（如准备笔试、修改简历）容易遗漏
4. 换了电脑或清理浏览器后，之前记录的数据全部丢失
5. 想分析自己的求职数据（投递转化率、面试通过率等）但没有工具

---

## 3. 功能模块

### 3.1 投递记录管理

#### 3.1.1 核心功能
- **添加投递**：记录公司名称、岗位名称、投递方式、投递日期、状态
- **状态流转**：支持13种状态（待投递、仅沟通、已投递、通过初筛、笔试、一面、二面、三面、已Offer、未通过、已接受、已拒绝、已放弃）
- **编辑/删除**：支持修改投递信息，删除后进入回收站（30天后自动清理）
- **详情查看**：点击投递记录查看完整信息，包括时间线、附件、链接

#### 3.1.2 扩展字段
- **行业/岗位分类**：手动输入，用于筛选和统计
- **工作地点**：支持按地点筛选
- **薪资范围**：记录期望或实际薪资
- **附件/链接**：上传简历、作品集等附件，或添加投递链接
- **备注**：记录额外信息

#### 3.1.3 列表展示
- 默认按最新添加排序（最新在上）
- 支持按状态、地点、关键词筛选
- 支持上下箭头调整排序

### 3.2 待办事项管理

#### 3.2.1 核心功能
- **添加待办**：记录待办内容、关联岗位（可选）、截止日期、优先级
- **完成标记**：勾选完成，支持取消完成
- **编辑/删除**：修改待办内容或删除
- **排序**：支持上下箭头调整顺序

#### 3.2.2 展示方式
- 按关联岗位分组展示
- 未关联的待办单独显示
- 已完成的待办可折叠

### 3.3 面经记录管理

#### 3.3.1 核心功能
- **添加面经**：关联投递记录，记录面试轮次（笔试/一面/二面/三面）、面试官、面试日期、内容
- **编辑/删除**：修改或删除面经
- **排序**：支持上下箭头调整顺序

#### 3.3.2 展示方式
- 按关联岗位分组展示（同待办）
- 每条面经以卡片形式横排展示

### 3.4 数据分析

#### 3.4.1 统计维度
- **投递漏斗**：待投递 → 已投递 → 推进中 → 获得Offer 的转化率
- **状态分布**：各状态投递数量占比
- **时间趋势**：近7天/30天投递趋势
- **公司/岗位分析**：投递最多的公司和岗位类型

#### 3.4.2 可视化
- 柱状图、饼图、折线图等多种图表
- 支持按周/月筛选

### 3.5 数据管理

#### 3.5.1 导出功能
- 支持导出 Excel 和 CSV
- 投递记录、待办事项、面经记录均可导出
- 支持自选导出字段

#### 3.5.2 云端同步
- 自动同步：操作后5~10秒内自动同步到云端
- 手动同步：支持立即同步到云端
- 从云端恢复：支持从云端恢复数据到本地
- 云端统计：显示云端投递/待办/面经数量

### 3.6 主题切换
- 支持多种配色主题
- 主题切换即时生效

## 4. 技术架构

### 4.1 前端技术栈
- React 18 + TypeScript + Vite
- Ant Design 5 + Tailwind CSS
- Zustand 状态管理
- Dexie.js (IndexedDB) 本地数据库

### 4.2 后端/云端
- Supabase (PostgreSQL + 认证服务)
- 行级安全策略 (RLS) 保障数据隔离
- 环境变量配置 (VITE_SUPABASE_URL, VITE_SUPABASE_ANON_KEY)

### 4.3 数据存储策略
- **本地优先**：所有操作先保存到本地 IndexedDB
- **自动同步**：联网后自动同步到云端
- **账号隔离**：不同账号使用独立的本地数据库

## 5. 用户场景

### 场景1：应届生海投管理
小明是应届毕业生，同时投递了50家公司。他使用 JobTracker 记录每家公司的投递状态，设置待办提醒准备笔试，记录每次面试的面经。通过数据分析，他发现自己的简历通过率是20%，面试通过率是50%，从而有针对性地改进。

### 场景2：跳槽者进度追踪
小红在职准备跳槽，利用碎片时间投递简历。她使用 JobTracker 记录每次投递，设置待办提醒跟进进度，面试后及时记录面经。通过时间线功能，她清楚知道每家公司的当前状态，避免错过重要节点。

### 场景3：跨设备数据同步
小李在公司的电脑上记录了投递信息，回家后想在手机上查看。他登录同一个账号，数据自动从云端同步到手机，随时随地管理求职进度。

---

## 6. 产品亮点

1. **极简操作**：添加投递只需填写公司和岗位，其他字段均为可选
2. **状态流转可视化**：清晰展示从投递到Offer的完整时间线
3. **智能分组**：待办和面经按岗位自动分组，一目了然
4. **数据安全**：本地+云端双保险，账号隔离保障隐私
5. **灵活导出**：支持多种格式和字段自选，方便备份和分析
6. **主题定制**：多种配色主题，满足不同审美偏好

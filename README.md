# 简历智能匹配工具 - 快速启动指南

## 🎯 当前状态

完整的React项目代码已完成，但需要Node.js环境来运行开发服务器。

## 📄 临时预览

1. 直接双击 `preview.html` 文件，可以在浏览器中看到产品功能预览
2. 预览页面展示了产品的核心功能和界面设计

## 🚀 启动完整应用

### 方法一：安装Node.js（推荐）

1. **下载Node.js**
   - 访问: https://nodejs.org
   - 下载 **LTS** 版本（长期支持版）
   - 运行安装程序，使用默认选项

2. **启动项目**
   - 安装Node.js后，双击 `start.bat` 文件
   - 或在项目目录手动运行:
     ```bash
     cd d:\简历匹配工具
     npm install
     npm run dev
     ```

3. **访问应用**
   - 打开浏览器访问: http://localhost:5173

### 方法二：检查已有Node.js

如果你之前已经安装过Node.js，请：

1. **以管理员身份打开命令提示符或PowerShell**
2. **运行以下命令检查**:
   ```bash
   node --version
   npm --version
   ```
3. **如果显示版本号，则说明Node.js已安装**

## 📁 项目文件说明

|------|------|

## 📞 需要帮助？

如果在安装或启动过程中遇到问题，请参考以下步骤：

1. 确保Node.js已正确安装（检查 `node --version`）
2. 确保在正确的项目目录中（`d:\简历匹配工具`）
3. 首次运行需要安装依赖（`npm install`）
4. 如遇到端口问题，可以尝试修改 vite.config.ts 中的端口
